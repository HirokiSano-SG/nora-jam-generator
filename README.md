# 野良ジャム告知文ジェネレーター

unity1week Team-Up!!（TU）サーバー内で有志が開催する「野良ジャム」の告知文を、フォーム入力から自動生成する非公式ツールです。

**使い方:** https://hirokisano-sg.github.io/nora-jam-generator/ を開いてフォームを埋め、「生成する」→「コピー」でDiscordに貼るだけ。

- 単一の `index.html` のみ（外部ライブラリ・ビルド不要）
- 入力内容はブラウザのlocalStorageに保存されるだけで、サーバーには送信されません
- 過去の野良ジャム告知文（野良ジャム・まろジャム・主題歌ジャム）を元にテンプレート化しています
- TU運営とは関係ない非公式ツールです
